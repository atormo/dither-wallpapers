# Dynamic Wallpapers

This directory contains the two installable 5120 × 3200 HEIC wallpapers.

## Polar Meadow Dynamic

`polar-meadow-dynamic.heic` follows the Mac's local system time:

| Time | State |
| --- | --- |
| 07:00 | Day |
| 15:00 | Sunset |
| 20:00 | Blue Hour |
| 22:30 | Night |

The wallpaper remains on Night after 22:30 and returns to Day at 07:00.

## Polar Day & Night Dynamic

`polar-day-night-dynamic.heic` follows the system appearance:

| Appearance | State |
| --- | --- |
| Light | Polar Bloom |
| Dark | Polar Night |

## Installation

1. Download the chosen HEIC and save it somewhere permanent.
2. In Finder, right-click the file and choose **Services → Set Desktop Picture**.
3. If it initially appears static, open **System Settings → Wallpaper**, select an Apple Dynamic Wallpaper in **Dynamic** mode, then set the downloaded HEIC again.
