## Download

### Complete collection

1. Click **[Download all 10 wallpapers](https://github.com/atormo/forma-wallpapers/releases/latest/download/forma-wallpapers.zip)**.
2. Open `forma-wallpapers.zip` once the download finishes.
3. Choose a wallpaper and set it from **System Settings → Wallpaper → Add Photo** on macOS.

### Individual wallpaper

1. Click a preview above to open its full-resolution file.
2. Use GitHub's download button, or save the image directly from your browser.

## Details

- **Resolution:** 5120 × 3200 pixels
- **Aspect ratio:** 16:10
- **Format:** high-quality JPEG
- **Finish:** smooth gradients with a consistent ordered-dither texture

The `previews` directory contains lightweight images used only by this README. The downloadable originals are stored in `forma-wallpapers`.
